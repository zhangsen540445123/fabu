# Fabu 设计：已获用户批准

## 目标和约束
Windows 11 单用户本地网页，输入授权的 YouTube 单个公开视频 URL 与标题；简介选填。
自动下载、普通 2K 处理、自动打开蚁小二、向抖音/头条号/哔哩哔哩三个明确账号投稿。
三平台分别获得可关联的已提交证据才算完成，不声称审核通过。
用户选择客户端界面自动化；不使用 CLI、付费 API、运行时大模型、隐式 API、固定坐标或登录凭证复制。
首版不包括剪辑/字幕/AI/播放列表/直播/定时排程，不绕过权限或验证码。
允许发布阶段在空闲、解锁状态占用桌面；正常工作不要求用户手动启动客户端。

## 技术和边界
Python3.12 FastAPI/Pydantic/SQLAlchemy+SQLite WAL，独立 Worker，React/TS/Vite 同源面板。
绑定127.0.0.1:17861，单worker单桌面控制者，Windows命名互斥锁；数据在%LOCALAPPDATA%/Fabu。
SourceDownloader inspect/download；MediaProcessor inspect/process；PublisherProvider ensure_ready/validate/submit/reconcile。
客户端特殊控件在发布模块，下载、处理、任务内核不耦合客户端。

## 视频
后台yt-dlp，本地EJS+Node，FFmpeg/ffprobe二进制；不自动读取浏览器cookies。
优先合适高画质，音画分离合并；横屏2560x1440、竖屏1440x2560边界，特殊比例等比内接。
偶数尺寸，不裁切、不拉伸、不补黑边；符合编码尺寸的源验证后可复用。
MP4 H264 yuv420p，libx264 CRF20 preset fast，AAC192k，原帧率保持。
HDR转SDR，不具备能力则暂停；无音源说明，不生成声音，不截短。
封面默认10%处取帧，可覆盖；成片验证尺寸/时长/轨道/完整性。
CPU是首版基线；硬件编码以后对比验证。

## 蚁小二
客户端4.14.6.1012，网页界面另有版本，不以exe版本推断控件稳定。
已观察快捷方式 C:/Users/Public/Desktop/蚁小二4.0.lnk；目标D:/automicDeploy/yixiaoer/yixiaoer-lite/蚁小二4.0.exe。
无参数，工作目录安装目录。曾无进程情况下直接双击lnk成功冷启动，读到已登录首页；也曾成功唤起。
正式ShellExecuteEx启动器及稳定控件和逐平台结果仍要实施验收。
查找配置快捷方式，使用正常Shell启动；已运行恢复窗口，不重复创建实例。
就绪最长90秒，仅确无进程允许第二次启动；有进程无窗口不循环启动；不强杀。
必要时通过UIA真实快捷方式默认动作回退，不用坐标。
UIA按语义定位，每步刷新状态；窗口存在/首页标题不等于发布准备完毕。
登录/验证码/既存非本程序任务/页面漂移必须暂停。
30秒人工空闲；检测人工输入、前台变化，忽略程序注入，不保存键盘内容。
账号以平台+稳定身份绑定，不只昵称/顺序；所有必填参数首次明确配置，不猜枚举/原创声明。
源视频、封面、文件和记录只由本程序拥有才可操作，不覆盖现有表单或上传任务。

## 一致性
创建幂等键+重复提示，输入和模板不可变快照；UUID命名文件。
每目标PENDING/SUBMITTING/SUBMITTED/FAILED/UNKNOWN，提交前持久化attempt。
只submit并不成功；reconcile必须唯一关联账号+本次提交记录。
SUBMITTED不重投；UNKNOWN禁止自动重发，不能新建重复任务绕过。
用户证据要可核对才改状态，无证据不能强制成功或重发。
取消只阻止未来操作，不删远端；恢复复用已验证下载/成片；转码中断重跑处理。
更改元数据创建关联修订，仅明确未提交目标，不能包含已提交/UNKNOWN。
源/成片/封面默认保留，磁盘不足暂停，媒体/秘密/日志不入Git。

## 选型比较
用户最终选择UIA，拒绝额外付费开放API及免费CLI；不自动变更路线。
第一阶段若不能稳定启动、识别账号/投稿控件、读取关联提交记录，不能继续宣称完整产品。
默认测试离线模拟，不正式投稿；实机发布必须授权测试视频和三个账号。
