# 发布契约核对记录

核对日期：2026-11-07。来源为本机已安装的官方蚁小二CLI 3.2.32随包schemas/references以及只读分类查询；没有执行上传、投稿、预约、草稿保存。

## CLI运行目录

`YIXIAOER_PROJECT_DIR`是CLI包根目录（包含schemas/references），不是Fabu源码目录。错误目录导致结构化用法错误“project directory not found”，并不等同于密钥失效。实际执行固定原生exe，不运行可能自动下载/升级的npm包装器。

## 标题与标签

- 抖音标题1–30字、描述1–1000字，schema支持1–10个字符串标签。
- 头条号标题1–30字、描述1–400字，1–5个标签，每标签最多20字。
- B站标题1–80字、描述最多2000字，1–10个标签，每标签最多20字。
- 当前三个schema的`tags`均为字符串数组；不会把标签名称伪装成`challenge`的真实平台ID或自行拼话题HTML。
- 文档说明CLI会改写描述中的`#话题`。首版对这种描述提示显式检查，不在用户不知情时改写。分组名不是标签内容。

## 来源声明

B站`createType=1`是自制，`2`是转载，转载需原URL。头条`declaration=1`是自行拍摄，`2`是取自站外。授权转载不能自动被声明为自己拍摄。各平台的AI、危险行为、引人不适等声明代码不同，必须按各自语义映射；不默认勾选独家、首发、共创或商业功能。

用户偏好原创不自动完成来源语义确认；模板需要逐平台明确选择。

## B站分类

对唯一匹配的已登录B站账号执行只读分类查询成功：生活经验的规范节点ID为1031，原始对象包含id与name。实际响应`dataList`为扁平列表，提供的完整路径只有“生活经验”，不能凭旧分类知识补造父节点。若今后返回children树或显式paths，则保留查询返回的整个父子路径与raw；raw内部同名字段不是另一条分类。

静态ID记录不是运行时可复用的账号绑定查询证据；发布准备需要当前账号的最近分类证据，过期要重新只读查询。

## 定时与免费能力的边界

三个schema接受毫秒时间戳字段，不证明定时已落到平台。`pubType=1`指直接提交，不是免费额度证明，也不是可让本机立刻关机的证据。真实原生预约必须核对平台级记录。

CLI的`query entitlements`帮助描述为购物车和团购权益，不是免费投稿额度接口。现有客户端免费次数不得直接作为CLI免费上传/投稿证据。OSS临时资源上传和本机发布通道是两个不同操作：选择local不代表完全没有云端素材上传；真实测试需明确覆盖这个副作用。

## 当前实现边界

本地PublishSnapshot保存标题、话题、成片/原封面摘要、账号、来源声明、分类和同一定时时间。准备快照检查任务CAS、内容修订、预览确认、处理计划和文件完整性。任一目标不合格整体拒绝；生成快照本身不授权上传或投稿。首次可能提交后的持久化冻结、恢复与防重由发布协调器承担。
