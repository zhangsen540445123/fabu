# 发布工作台：当前使用范围与安全边界

## 两种环境不能混淆

- **本地仿真**：使用 `sim-` 开头的合成账号、合成上传回执和平台结果。没有网络发布，也不消耗真实平台次数。用来验证流程、失败停止、预约时间换算和重启恢复。
- **真实账号（仅配置与预检）**：可以保存发布元数据、查看原封面/成片绑定、选择稳定账号ID并构建不可变快照。**实际上传、投稿、预约尚未解锁**。浏览器传入 `scope=live` 不能绕过后端门槛。

“已被蚁小二接收”“平台已提交”“平台已预约”“平台已公开”分别显示。仿真结果始终有明确标记，不能作为真实发布验收证据。

## 配置连接（不会发布）

1. 打开侧栏“账号与发布”。
2. 填入官方CLI包目录：目录内须有 `bin-native/yxer.exe`、`schemas` 和 `references`。这里不是项目仓库目录，也不是 `.bin/yxer.cmd`。
3. 输入自己的 API Key 和本地发布客户端ID，选择“加密保存连接配置”。密钥和客户端ID不会在读取接口回显，也不会写进仓库。密钥使用当前Windows用户的DPAPI加密保存。
4. 点击“只读同步真实账号与B站分类”。当前只执行固定版本检查、账号列表和B站视频分类查询；不执行上传/投稿，不查询与发布额度无关的购物类 entitlements。
5. 使用稳定ID分辨同名账号。真实账号不会默认全选，需在任务里明确选择。

CLI是命令行工具，不是智能体。连接配置不会自动解锁免费额度、HEVC支持或平台原生定时能力。若曾公开过旧Key，应先在服务端撤销并替换；本项目不会假定旧Key已经撤销。

## 单个任务

1. 完成本地下载、样片确认和完整成片验证。
2. 打开任务详情的“发布配置与结果”，选择发布环境和目标账号。
3. 选择话题：标题中“剃须仙人”“剃光头”“剪发”分别匹配已确认话题组；零个或多个命中必须手动选择，手动覆盖优先。
4. 明确来源声明。授权转载不等于本人原创；B站原创/转载与头条自行拍摄/站外取材根据明确来源生成，不能自动把授权变成自制。
5. 视频固定为本任务已验证成片，封面固定为该YouTube视频原封面。B站分类使用账号只读查询取得的完整“生活经验”路径，而不是浏览器上传任意分类对象。
6. 预约输入按 **Asia/Shanghai（北京时间）** 转换为UTC，与浏览器所在时区无关。过期预约不会转为立即发布，也不会用本地定时上传冒充平台预约。
7. “保存配置并预检”只保存元数据并校验，不会发布。更改发布元数据生成新内容版本，但保留未改变的已验证媒体与处理快照，不要求无意义重编码。
8. 在仿真环境通过预检后，可选择“开始本地仿真”。任务与视频处理共用一个Windows Worker，重任务串行执行。

## 异常与恢复

- 某目标失败或结果不明时，后面的未提交目标立即停止。
- 已有唯一平台证据的目标不重发；已确认未提交的失败才允许有限续跑。
- UNKNOWN只提供“查询对账（不重投）”。不能通过通用媒体“继续”、换标题或换预设绕过不明提交。
- 进程重启会保留提交尝试，将不确定的提交标记为UNKNOWN，未执行队列不自动再次提交。需重新检查状态。
- 取消本地仿真不会把已产生的回执抹掉，也不会声称撤销了先前提交。
- 第一笔可能的真实提交前会事务性冻结共享内容；修改预约或删除远端作品必须去对应平台处理，不能假定跨平台原子撤销。
