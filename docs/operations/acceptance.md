## 用户PowerShell实机核对（不发布）

在自己的终端运行README中的安装检查和启动命令，确认：

- [ ] 报告显示自己的状态/媒体/工具目录，FFmpeg/ffprobe/Node路径均正确。
- [ ] 第一次打开浏览器正常进入工作台，不需复制密钥到对话。
- [ ] 关闭网页后再运行启动脚本，复用同一PID，不出现第二个Worker。
- [ ] 已下载源视频和处理预设仍在；没有自动上传或投稿。
- [ ] 在“账号与发布”配置新产品的加密连接；不读取或复制旧探测脚本的auth.json到仓库。
- [ ] 只读同步三个指定平台的账号与B站生活经验分类，核对稳定ID与昵称。
- [ ] 执行停止脚本后Fabu退出，但其他Python/FFmpeg/剪映/蚁小二程序不受影响。

自动化工具运行Windows PowerShell是真实系统壳层测试，但不能替代用户本人确认其日常终端、浏览器与平台账户环境。

## 真实发布实测前还需要

- 能访问且允许下载的视频源；需要认证时必须采用用户明确配置的合法访问方式，不能暗取登录态。
- 具体媒体/封面/标题/话题/来源声明、三目标稳定账号、立即或明确北京时间、最大尝试次数的本次授权。
- 当前免费额度、临时存储、失败扣次及最坏费用上限的原始证据，货币支出上限0。
- 先运行本地预检与严格范围检查，再按授权进行受控测试；失败/不明停止，不自动购额或改路线。
