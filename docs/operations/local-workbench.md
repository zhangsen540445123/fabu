# 本地工作台：开发预览说明

## 当前可以验证的功能

- 列表式处理流水线：截取、变速、裁切、翻转、调色、画布装饰、图片/文字、SRT、片头片尾、音量和淡入淡出。
- 不可变预设版本；已有任务不会跟着全局预设变化。更换任务预设会创建新内容版本。
- 串行后台处理；下载、预览、全片渲染不在同一个应用实例里争抢执行。
- 首次或参数变更时暂停等待样片确认；观看代理与正式HEVC样片分开，确认后继续生成成片。
- 已验证成片下载、取消和故障后恢复；素材文件名不作为FFmpeg语法。

**当前仍是开发预览，不是完成的发布产品。** 示例YouTube视频的实际下载仍遇到登录验证；浏览器端到端测试注入了本地合成素材，只证明界面和真实FFmpeg处理链路，不证明真实网络下载。发布功能保持禁用，尚未上传、投稿或预约。

## 开发环境启动

在项目目录用已创建的Python虚拟环境启动：

```powershell
& '.\.venv\Scripts\python.exe' -m fabu --open-browser
```

该入口启动本机127.0.0.1服务，并打开一次性受保护的浏览器会话。不要将启动令牌、凭证文件或聊天中出现过的旧密钥贴入日志。

运行设置需要：

1. 媒体保存目录：用于下载中间文件、样片及成片。有任务时不能直接切换目录。
2. 工具目录：包含经过核查的`ffmpeg.exe`与`ffprobe.exe`。不会自动搜索、升级或安装。
3. Node.js可执行文件：选择已安装的`node.exe`绝对路径，供YouTube下载器执行所需脚本。不会读取浏览器cookies。

未配置工具时后台保持等待，并在界面说明原因；不以失败候选文件或原视频冒充输出。

## 建议的使用顺序

1. 在“处理流水线”导入需要的本地图片、视频、TTF/OTF字体或UTF-8 SRT文件。素材会复制到受保护的素材库，原文件不变。
2. 添加处理项，勾选开关并设置作用范围。时间处理在画面操作之前，主片图层在拼接之前，整片图层在拼接之后；非法顺序只报告，不自动重排。
3. 保存预设版本，再创建任务，填写YouTube链接和标题并选择预设。标题变化不会更换处理模板。
4. 未确认预设的任务会暂停。打开任务详情生成样片，可选择自定义区间；默认正文15秒并覆盖片段及关键图层边界。
5. 观看代理用于浏览器兼容播放，正式HEVC样片保留真实输出参数。检查后勾选确认，再继续完整处理。
6. 只有完整性和格式验证成功，状态才变为“成片就绪”。下载入口会再次检查文件摘要。

字幕字体必须覆盖所用字符，图片片头/片尾必须指定时长；超界字幕、缺失素材、错误字体或不兼容色彩会暂停，不静默替代。

处理不改变素材版权或平台来源要求，也不保证规避平台查重。不得把授权转载自动解释为自己拍摄。

## 测试证据边界

测试用例和本地样片在当前工作树执行。浏览器夹具位于`frontend/tests/serve_fixture.py`，使用合成音画及固定测试令牌，不能作为生产配置或网络成功证据。真实用户原片的完整2K转码证据另保存在媒体子计划的`real-render`目录。

真实YouTube下载、官方CLI免费写入权益、三个平台的立即发布与平台原生定时，仍需各自独立验证；尤其真实上传/投稿需具体媒体、账号、模式/时间和次数授权。
