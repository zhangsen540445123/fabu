# 默认发布配置与自动预检

## 已实现
- “发布配置与结果”可保存全局默认发布配置，不要求先投稿，不修改当前任务。
- 新任务自动选中已保存的默认流程；可明确改为“仅本地处理”或选择其他模板。
- 默认配置绑定保存时的稳定账号 ID，不会在同步目录后悄悄增加新账号。
- 可保存真实账号环境、3 个账号、按标题选话题、本人原创、来源确认和立即发布。
- 原创及确认来自用户显式保存的声明，不是软件根据下载、转码或剪辑推断出的版权结论。
- 定时仍然表示平台原生预约；保存默认配置不复制某次任务的预约时间。
- 打开任务时，任务已保存草稿 > 任务固定流程模板 > 全局默认值 > 未配置状态。已有转载声明、平台附加声明、描述及定时时间不会被默认值覆盖。
- 手动保存任务发布配置会解除旧自动模板绑定，避免旧模板再次覆盖本次修改。

## 处理后的状态
真实流程：下载完整性检查 → 预设处理 → 成片完整验证 → 自动发布预检 → 显示当前阻塞原因。

当前真实上传/投稿仍未通过免费额度、平台能力及正式验收，因此自动流程停在 `live_publish_not_enabled`，不创建上传、投稿命令或发布记录。输出仍为 READY、可下载。这个状态**不是平台发布成功**。原有正式投稿媒体批准策略、来源校验、免费额度与授权门禁均未解除。

账号临时失效或本机预检中断时，成片仍保持 READY 可下载；修复原因后可点击“重试发布预检（不上传）”。该操作不重新渲染、不授权上传，存在结果不明的历史尝试或来源占用时不可重试。

仿真模板仍按原有方式自动衔接仿真发布；不调用真实传输。

标题规则：
- `剃须仙人` → `WRHkkYwU`
- `剃光头` → `2aZjVP8u`
- `剪发` → `QKHLZMFO`
- 标题无匹配或多义，不猜测组别；需明确选择话题模板后再创建自动任务。

账号失效或缺失不自动缩减目标；先核对同步情况，再由用户取消或修改选择。现有本地任务不会因保存默认配置而自动恢复或发布。

## 接口
- `GET /api/publishing/defaults`：读取指向不可变模板的默认设置。
- `PUT /api/publishing/defaults`：会话 + CSRF 校验后保存，必须传明确账号及已确认声明。
- `GET /api/jobs/{id}/publication`：只读返回任务表单及来源（draft/profile/default/fallback）。
- `GET /api/workflow/jobs/{id}/handoff`：自动衔接状态。

数据库迁移 `010_publication_defaults.sql` 只增加默认指针，不迁移、重写或批准历史任务。

## 验证
隔离测试使用本地合成媒体与合成账号，没有真实发布。覆盖：历史数据不变、默认持久化、固定三账号、来源优先级、账号缺失拒绝、成片损坏拒绝、自动预检一次执行、平台提交接口仍拒绝、浏览器刷新恢复默认与端到端自动流转。
