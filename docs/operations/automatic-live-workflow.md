# 新任务自动真实发布（2026-11-08）

## 默认操作
通过桌面的“启动 Fabu”打开认证页面。新建自动工作流时只需要输入 YouTube 单视频链接和标题；默认处理预设、发布配置、三个账号、来源声明、立即发布来自已保存配置。页面明确说明这是自动真实发布，而不是无副作用的本地任务。

下载与处理每个阶段完成完整性检查后才继续。所选预设不再要求逐任务样片确认。封面来自视频原始缩略图；标题必须唯一匹配既有话题规则，否则暂停并要求选择，不猜话题。

处理完成后：上传成片及封面各一次，验证远端 bucket/key/大小/宽高/时长；各账号分别执行 `--publish-channel local`，一平台一个任务组。收到某账号的合法接收回执后继续下一个账号。网络超时或不明确响应停止剩余目标，不自动重发。旧任务不会因安装、启用或重启继承新任务授权。

## 状态不是同一回事
- **已被蚁小二接收**：CLI 返回了与这次命令绑定的 taskSetId，尚不是平台成片质量通过。
- **等待平台结果**：后台只读跟踪；正常等待不要求手动推进。
- **服务商报告成功**：query details 的任务状态，平台公开状态和成片时长仍待独立核实。
- **平台成片质量未验收**：尤其 B 站历史 2 秒问题未根因修复；不能用本地 713 秒、上传成功或 provider success 掩盖。

跟踪首次30秒后进行，失败有指数退避，单任务上限120次／连续8次错误／24小时。重启保留次数与截止时间；手动刷新不绕过上限。只读跟踪不重投、不删除、不改可见性。

## 免费预算
接受用户已选择的三平台三任务方案。应用每日按北京时间最多预留三个目标投稿，上传前预留，失败不自动退还。本地账本包括导入的历史投稿，但无法观察其它软件中的所有手动发布，**不等于官方剩余额度查询**。外部额度不足时可能被拒绝；无付费、充值、订阅或云发布回退。

## 新任务授权
真实自动功能默认关闭。受信任本机配置命令绑定已审核 CLI 可执行文件、客户端和凭证身份；只对之后在认证页面创建的新自动任务记录授权。不是全局放行历史任务，也不把 UNKNOWN 能力伪造为已验收。

```powershell
& 'D:\auto-deploy\.venv\Scripts\python.exe' -I -X utf8 -m fabu.publishing.setup --enable-new-jobs --acknowledge-three-tasks
```

本机已依据用户本次“打通全流程”请求启用；默认处理预设使用已有自动CPU/GPU版本。换CLI/账号身份后安全暂停，需重新核对配置。平台原生预约暂未验收，禁止自动改成立即发布。

## Windows物理存储一致性
MSIX会将逻辑 `%LOCALAPPDATA%\Fabu` 文件虚拟化到应用私有 LocalCache。`scripts/start-fabu.profile.json` 为**机器本地、Git忽略**的物理状态目录选择，不含密钥。启动/停止BAT均读取它。不要删除旧物理库、重建空库或把虚拟与普通目录随意合并。

此次使用原任务和凭证所在的物理目录；CLI包路径及已配置Chrome native host也指向同一物理目录。Chrome助手必须已启用且连接，才能在YouTube要求登录时按需提供会话；浏览器关闭或YouTube要求人工验证时仍会暂停，不绕过挑战。
